# CPS769_2

Pytangram models for multi-phase quantum decay chains.

## Files

- `erlang.py` — Interactive K-phase model (prompts for parameters)
- `sweep.py` — Sweeps sigma1/sigma2, saves JSON + plots
- `sweep_results.json` — Sweep data for plotting
- `results.json` — Individual run results (appended)
- `good_put_vs_sigma1.png` — Good put vs sigma1
- `good_put_vs_sigma2.png` — Good put vs sigma2
- `good_put_contour.png` — Good put contour plot
